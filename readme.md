# T-Rust
This is a CLI Game with the name T-Rust which can be interpreted in multiple ways, such as Treasure Rust, which is the game's theme, Trust, since you have to trust in your gaming skills to beat this game, or simply, T-Rust, as in the letter T, but no matter what you interpret the name as, Rust is always involved.

# Self Hosting
1 - **Fork the repository (duh)**<br>
2 - **In your terminal write ```git clone https://github.com/MustafaBioS/t-rust.git```**<br>
3 - **in the directory where you cloned the project, ```cd t-rust```**<br>
4 - **```cargo run```**

# Features
T-Rust has multiple features including, but not limited to:**
- **Main Menu**
- **Pausing Functionality**
- **Seed-Based Generated Terrain**
- **Jump and Gravity Functionality**
- **Lootable Treasure Chests**

# Keybinds
> **A / Left Arrow** -> Move Backwards<br>
> **D / Right Arrow** -> Move Forward<br>
> **Space / Up Arrow** -> Jump<br>
> **ESC / P** -> Pause<br>
